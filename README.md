# Setlyst

Setlyst is a COS 333 project repository.

## Overview

Setlyst will be developed as a team software engineering project. This repository is the home for planning notes, project documentation, source code, issue tracking, pull requests, and release materials.

## Repository Structure

```text
.
├── docs/                 Project planning and design notes
├── src/                  Application source code
└── tests/                Automated tests
```

The `src/` and `tests/` directories are placeholders until the implementation stack is finalized.

## Getting Started

Setup instructions will be added once the team chooses the application framework, package manager, and runtime.

## Team Workflow

- Track tasks and bugs with GitHub Issues.
- Use branches for feature work.
- Open pull requests for changes to `main`.
- Keep commits focused and describe the user-facing change or project decision.

## COS 333 Notes

Course deliverables, design decisions, meeting notes, and milestone updates should live in `docs/` so they are easy to find during demos and reviews.
