# Team Workflow

## Weekly Rhythm

- Review open issues.
- Assign owners for the next set of tasks.
- Merge reviewed work into `main`.
- Record important decisions in `docs/`.

## Issue Labels

Suggested labels:

- `feature`
- `bug`
- `docs`
- `design`
- `testing`
- `blocked`

## Definition of Done

A task is done when:

- The intended behavior is implemented.
- Relevant documentation is updated.
- Relevant checks pass.
- The change has been reviewed if it affects shared code.
