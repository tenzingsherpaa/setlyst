# Contributing

## Branches

Create a branch for each task:

```text
feature/short-description
fix/short-description
docs/short-description
```

## Pull Requests

Before opening a pull request:

- Make sure the change is focused.
- Update docs when behavior or setup changes.
- Run the relevant checks once they exist.
- Link the related GitHub issue when possible.

## Reviews

Reviewers should look for correctness, clarity, maintainability, and test coverage. Comments should be specific enough for the author to act on.
